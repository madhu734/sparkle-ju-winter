# Sparkle — JU Winter Edition ✦

Mobile-first e-commerce web platform for collegiate winter bonded jackets & hoodies, tailored for Jahangirnagar University campus.

## ✦ Key Highlights
- **Product Offerings:**
  - Premium Waterproof Double-Part Bonded Jackets (Sizes: S, M, L, XL, 2XL)
  - Winter Collegiate Hoodies (Sizes: M, L, XL)
- **Direct Campus Trial:** Physical sample inspection & trial spot at Sahid Rafiq Jabbar Hall, Generator Bazar, Bottola, JU.
- **Dynamic PocketBase Backend:** Real-time catalog & multi-photo gallery powered by self-hosted PocketBase.
- **Convenient Checkout:** Free campus delivery across all halls with COD, bKash, and Nagad payment options.
- **High-Fidelity Typography & Design:** Mobile-first editorial aesthetics with dark/light themes and dual bilingual English/Bengali (`EN | বাং`) support.

## ✦ Tech Stack
- **Frontend:** React 19, Vite, Tailwind CSS v4, Lucide React
- **Backend:** PocketBase (`https://spb.tmadhu.me`)
- **Containerization:** Multi-stage Docker + Alpine Nginx
- **Hosting:** Self-hosted Coolify PaaS with automated push-to-deploy Git webhooks

## ✦ Local Development

```bash
npm install
npm run dev
```
